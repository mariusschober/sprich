## 1. Scope — what sprint 3 was asked to convert

The senior review identified 9 high-leverage sprints:

1. Swipe-up keyboard switch + minimal gesture language (frequency / reversibility / discoverability)
2. Correctness polish (KeyEvent duplication, legacy audio path, bounded PCM copies, runBlocking trap)
3. Native SLID blocker diagnosis + heap-bounded sequential lid→fast
4. Lifecycle + main-thread wall + hot-path log gates + reflection cache
5. Optional parallel TinyLID→FastConformer (measured vs reverted)
6. Single coalesced visual/haptic lane (kill random animators)
7. Product copy + Settings information architecture rewrite (jargon-free)
8. Real editor matrix harness beyond FakeIC
9. Release / R8 / 16 KB / adaptive icon / signing / licenses

Frozen constraints preserved without reopening:

*   Production Automatic = `PCM → Whisper Tiny LID (98M) → FastConformer CTC 126M` (224 MB, no Canary)
*   Accurate = `PCM → Canary 180M Flash INT8`
*   Cloud = BYOK only (`device → user's provider`, Muse `https://api.meta.ai` + Gemini `generativelanguage.googleapis.com` locked), local remains useful without keys
*   Invariants: `one utterance → one plan → one PCM → ≤1 commit`, `stale → 0`, `cancel → 0 fallback`, `API_PRIMARY success → 0 local loads`
