# Current limitations

See [release/REVIEW.md](../release/REVIEW.md) for measured acceptance against the current artifact. Dated sprint reports describe older builds.

- ARM64 only, Android API 26–36. No 32-bit, x86 or pre-Android-8 package.
- Dictation and the interface support English, German, Spanish and French. The interface follows Android, while dictation language is chosen independently. Unsupported speech is not translated.
- Large offline speech files require a one-time download and spare installation space. Automatic detects the language per utterance; if language detection fails or returns an unsupported language, the utterance is not inserted (fail-closed, no guessed language). Accurate requires an explicit language.
- Moving the cursor/selection, changing field or hiding the keyboard cancels uninserted words. Review inserted text; speech recognition is fallible.
- Conservative editor checks can refuse an insertion/deletion in editors that do not expose sufficient reliable context. Sprich never retries an ambiguous mutation.
- Cloud providers are disabled in production. Mock/adapter tests establish error handling, not live provider readiness.
- Recovery text (E6): after an insertion fails or the field is abandoned, recognized text is held only in a bounded in-memory draft — one draft, at most 16,384 characters, 120-second lifetime — for the Home review/discard card. It is not bound to a field, is cleared on lock/discard/expiry/process death, and is never inserted automatically. The former unlimited same-field retry copy was removed together with the unreachable retry affordance; no recovery path bypasses fresh editor proof.
- Accuracy evidence is public read speech only: the 2026-10-25 bake-off used FLEURS test clips (CC-BY-4.0, 50 per language) plus synthetic silence/noise on the TCL T807D. It is not the maintainer's voice, spontaneous speech, accents, café/TV/headset conditions. A 20-clip-per-language acoustic subset was additionally measured through Mac-speaker playback into the TCL microphone and a real editor (production Canary: 80/80 insertions, overall WER 0.096; loudspeaker playback, not human speech at natural distance). The Parakeet candidate has no acoustic number (BLOCKED: debug-only engine without editor routing). A Common Voice English German-accented subset could not be obtained (BLOCKED: the repository exposes no anonymous data files), so it is absent rather than approximated.
- In that measured run Canary produced no text on 7 of 50 English FLEURS clips (durations 6.6-14.9 s); the cause is not yet diagnosed. Long English input may therefore insert nothing; review before relying on it.
- The debug-only NVIDIA Parakeet TDT 0.6B v3 candidate was evaluated and rejected for 1.0: its German WER was 45% worse relative to Canary (0.096 vs 0.066 mean per clip), warm PSS was about 1,219 MB versus 553 MB for Canary, and the fifteen-minute stability run did not qualify it. It is not in the production manifest or download flow.
- Long acoustic fixtures do not replace spontaneous speech. USB tests do not measure unplugged battery life.
- Zapstore publication requires a permanent Android app signer and Nostr publisher identity. The first signing setup was deferred. See the release handoff for the remaining publisher steps.
- NVIDIA NGC-licensed FastConformer is not part of the production configuration because those terms prohibit public redistribution; Automatic uses Whisper Tiny language detection plus Canary 180M Flash. Existing installations may keep the obsolete files until the replacement (language detection plus Canary) verifies, then they are deleted automatically. Play and F-Droid publication are outside the current scope; no source-only F-Droid build-chain claim is made.
